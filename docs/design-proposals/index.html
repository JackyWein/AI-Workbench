Why it feels premium

28px rows, icon-label alignment, app switcher + ⌘K search, unread counts, tabular numbers, user card with usage — the Linear sidebar grammar.

Chat as document

Assistant = prose with timestamps; code block has line numbers + copy; tool calls collapse to one mono row. Hover actions (copy/retry/branch) stay faint until needed. Streaming = caret + Stop chip.

Property panel

Label/value rows, thin context meter, skill chips, MCP mini-switches instead of dots. Amber badges in the sidebar mark what needs you — muted counts stay quiet.

Identity, not boxes

Provider avatar chips in rail + tiles, unread badges (amber when action is needed), filter with ⌘F. You can tell the four agents apart at a glance.

Tiles carry their kind

Solos show fade-masked terminal output; the team shows a task checklist with owners + blocked state; approval shows a diffstat with inline Approve/Dismiss. Segmented bars encode done/blocked/rest.

Same model as Island

Running list, dots, pills mirror the Status Island exactly — one mental model, two surfaces.

Raycast grammar, grounded: the actual console (design A) sits dimmed + blurred behind the scrim, one 600px omnibar with a live caret, match-highlighted results, and a key-hint footer. Boot-optional, always one ⌘K away.

The backdrop is design A itself — real rows, real chat rhythm, code block, composer — dimmed and blurred. The palette reads as a layer over the app, not a dialog from nowhere.

Contained risk

Blur + 14px radius exist only on this overlay (§71-legal). Nothing else in the app changes; boot-to-palette stays a toggle.
