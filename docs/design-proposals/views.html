Notch grammar, any edge

Top-center reads as the Mac notch; sides rotate the pill vertical (mark + elapsed). Same marks, hairlines and tabular numerals as the console.

States, not screens

Approval and question stack multiple items in a scrolling card (Approve all on top); working fills out with ask + usage. Hover closes the moment a drag starts; open cards never compete with the drag.

Click expands the dock

Working opens a rich agent panel (rows, live question with ⌘-options, ask input); idle shows stats + usage. Approval arrives glowing amber with a capped pretty diff. Dragging off collapses back to the blob.
