# AI Workbench

AI Workbench is a planned local desktop environment for running multiple AI providers, persistent project sessions, shared skills/plugins/MCP integrations and autonomous multi-agent teams from one interface.

The authoritative specification is:

- `AI_WORKBENCH.md`

Coding-agent instructions:

- `CLAUDE.md`

Verified project status:

- `PROGRESS.md`

## Current stage

Fresh repository / foundation.

The first target is a working Electron + React + TypeScript vertical slice using a MockProvider before real provider integrations are added.

## Core principle

**Simple by default. Powerful on demand. Provider-independent from the first line of code.**
